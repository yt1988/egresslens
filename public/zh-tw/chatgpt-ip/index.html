常見問題

怎麼知道 ChatGPT 和 Claude 看到的是什麼？

chatgpt.com、openai.com、claude.ai、anthropic.com 等 AI 網站都在 Cloudflare 後面，自己的網域下有 /cdn-cgi/trace，會回傳連過來的 IP，以及 Cloudflare 判定的國家。瀏覽器依你的規則幫每個網站選的線路去詢問，讀到的就是它們看到的。

哪些地區不受支援？

OpenAI 和 Anthropic 都不在中國大陸、香港、澳門、俄羅斯、白俄羅斯、伊朗、北韓、敘利亞和古巴提供服務。AI 網站看到你在這些地區時，註冊和使用都可能被擋。換一個支援地區的節點，再測一次確認。

為什麼 ChatGPT 看到的 IP 和其他網站不一樣？

因為代理規則常把 AI 的網域分到獨立的節點。這個頁面把每個 AI 服務的出口和其他網站放在一起，一眼就能看出規則是不是照你的意思在走。

機房 IP 有影響嗎？

多少有一些。雲端伺服器和機房的 IP 由很多人共用，比較容易遇到人機驗證和使用限制；家用寬頻或行動網路的出口被標記的機會小一些。

為什麼不同網站看到的 IP 不一樣？

因為你的代理在依規則分流。Clash、Surge、Shadowrocket、sing-box 這類有規則的代理和 VPN，會依要去的網站選線路：中國大陸網站直連，AI 服務走一個節點，其他網站走另一個。所以只查一個網站，只能看到其中一條線路。這個頁面同時詢問幾十個地方，再依網路把結果歸成幾個出口。

什麼是 WebRTC 外洩？

就是代理沒顧到的一條路，你的真實 IP 可能從這裡外洩。WebRTC 是瀏覽器用來做視訊通話的功能，它會透過 UDP 向 STUN 伺服器詢問「我的公開 IP 是多少」。很多代理只轉送 TCP，這個 UDP 請求就會直接從你自己的線路出去；而且任何網頁都讀得到結果，不會跳出提示。如果 STUN 伺服器看到的是本地 IP，網站看到的卻是代理，頁面就會回報外洩。想要堵住，可以在代理裡開啟 UDP 轉送或 TUN 模式，或用瀏覽器擴充功能限制 WebRTC。

什麼是 IPv6 外洩？

代理只處理 IPv4，而你的線路又有 IPv6 時，走 IPv6 的連線可能繞過代理直接出去。「僅 IPv6」那組檢測點會顯示 IPv6 流量實際從哪個出口出去。如果回報外洩，可以讓代理也接管 IPv6，或在系統或路由器裡關閉 IPv6。

怎麼分辨本地出口和代理出口？

看 IP 屬於誰。登記在雲端服務商或機房名下（Amazon、Google Cloud、阿里雲、DigitalOcean 等）的 IP 標為代理；第一個屬於電信業者的 IP 當作你的本地線路。所以住宅代理，或架在電信業者網路上的 VPN，用這個方法分辨不出來。

「本站東京伺服器」那組測的是什麼？

那是 1ms.dog 自己放在東京的一台伺服器。其他檢測點換的是目的地，這組換的是連接埠和協定：同一個位址，用 TCP 連 443、4433、8080、8443、9443、10443，再用 UDP（STUN）詢問 3478、19302、51820、40000。目的地沒變，出口卻不一樣，就表示你的代理依連接埠或協定分流，例如只接管了 TCP。443 那一項還會讀出 MSS（每個 TCP 封包最多裝多少資料）：明顯小於常見的 1460 時，這條線路可能套了一層隧道，例如 VPN。電信業者的隧道和部分行動網路也會這樣，所以這只是參考。

檢測結果會傳到這個網站嗎？

不會。瀏覽器直接詢問每個檢測點，本站只提供靜態網頁，看不到你的結果。本站自己的檢測點（「本站」那一項和「本站東京伺服器」那組）會看到你連線用的 IP 和連接埠，只原樣回傳給你，不做記錄。另外有兩種情況由你自己決定：「分享」會把結果寫進連結 # 後面的部分，開啟連結時這部分不會傳給伺服器；「回報問題」會附上這次檢測的概況，不含 IP 位址。截圖前可以先按「隱藏 IP」。
